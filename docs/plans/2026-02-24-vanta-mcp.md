# Vanta MCP Integration — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Enable the passion group to query Vanta compliance data via the official `@vantasdk/vanta-mcp-server` MCP server.

**Architecture:** Config-only integration following the established NanoClaw MCP pattern. Secrets flow from `.env` → `readSecrets()` → stdin → `sdkEnv` → SDK interpolates into `settings.json`. No new code logic, only allowlist expansions and config changes.

**Tech Stack:** `@vantasdk/vanta-mcp-server` (npm), Claude Code SDK settings.json MCP config

**Design doc:** `docs/plans/2026-02-24-vanta-mcp-design.md`

### Task 3: Configure Vanta MCP server for passion group

**Files:**
- Modify: `data/sessions/passion/.claude/settings.json`

**Step 1: Add vanta MCP server to settings.json**

Add `"vanta"` entry to the existing `mcpServers` block. The full file should be:

```json
{
  "env": {
    "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1",
    "CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD": "1",
    "CLAUDE_CODE_DISABLE_AUTO_MEMORY": "0",
    "MCP_TIMEOUT": "30000"
  },
  "mcpServers": {
    "google-workspace": {
      "type": "stdio",
      "command": "uvx",
      "args": ["workspace-mcp", "--single-user", "--tools", "gmail", "calendar", "drive", "sheets", "docs", "slides", "search", "appscript"],
      "env": {
        "GOOGLE_OAUTH_CLIENT_ID": "${GOOGLE_OAUTH_CLIENT_ID}",
        "GOOGLE_OAUTH_CLIENT_SECRET": "${GOOGLE_OAUTH_CLIENT_SECRET}",
        "USER_GOOGLE_EMAIL": "${PASSION_GOOGLE_EMAIL}",
        "GOOGLE_MCP_CREDENTIALS_DIR": "/workspace/extra/google-workspace-mcp/credentials"
      }
    },
    "vanta": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@vantasdk/vanta-mcp-server"],
      "env": {
        "VANTA_API_TOKEN": "${VANTA_API_TOKEN}"
      }
    }
  }
}
```

**Step 2: Validate JSON syntax**

**Step 4: Commit**
